# Trimen Tractors website

New version of [trimentractors.com](https://www.trimentractors.com/en) in English, German, Russian and Latvian. It is a static site: plain HTML pages generated by a Python script, with one CSS file and one small JavaScript file. No server or database is needed.

## What is on the site

* Home page with stock search, categories, recent arrivals and contact details
* Group pages (Machinery, Trucks, Work tools) and a page per category, with filters for make, mounting type, width and price
* A page for every machine and work tool: photos, price with and without VAT, specifications, description and the responsible salesperson
* About page with address, map, sales team, company details and photos
* Search-engine setup: sitemap, hreflang between languages, structured data, and redirects from the old site's URLs. See [SEO.md](SEO.md) for the full review.

## Folders

| Path | What it is |
|---|---|
| `scripts/scrape.py` | Reads the current stock from the old site into `data/stock.json` |
| `data/overrides.json` | Hand corrections: item types, makes and models, translated dealer notes |
| `scripts/content.py` | All site text in four languages: categories, labels, page copy |
| `scripts/build.py` | Generates the pages into `en/`, `de/`, `ru/`, `lv/` plus `sitemap.xml` |
| `scripts/check.py` | Checks the built pages for broken links and SEO problems |
| `assets/` | Stylesheet, script, logo and icons |

Everything in `en/`, `de/`, `ru/`, `lv/`, `index.html`, `404.html`, `sitemap.xml` and `robots.txt` is generated. Edit the scripts, data or `content.py`, not those files.

## Updating the stock

```bash
python scripts/scrape.py
```

```bash
python scripts/build.py
```

```bash
python scripts/check.py
```

Then commit and push. Python 3.9 or newer, no extra packages.

## Preview and live builds

`python scripts/build.py` makes a preview build: every page carries `noindex`, so the GitHub Pages copy stays out of Google. For the real domain:

```bash
python scripts/build.py --production
```

Canonical links, hreflang and the sitemap use `https://www.trimentractors.com`. Pass `--site-url` to build for another address.

## Viewing locally

```bash
python -m http.server 8000
```

Then open http://localhost:8000/en/.

## Offers section and request form

The "Current offers" section on the home page and the rotating offer in the header photo show machines and trucks with a price and photos. Choose which ones come first in `data/overrides.json`:

```json
"featured": [3338, 3302, 3065]
```

The rest are filled in from the newest listings. To show a reduced price, give the item its earlier price; the listing then gets a "Reduced" badge and the old price struck through:

```json
"3302": {"was_price": 49500}
```

The "Send a request" form opens the visitor's email app with the message addressed to the salesperson who handles most listings of that kind (machinery and trucks, or work tools). A shared address such as info@ can replace this in `request_to` in `scripts/build.py`.

## Notes

* Photos are loaded from `trimentractors.com/upload/...`. Copy them to the new host before the old server is switched off.
* The logo is the existing 147×58 PNG. Replace `assets/logo.png` (or add an SVG) when a vector version is available.
